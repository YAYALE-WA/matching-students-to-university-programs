# 评测方法

仅维护或验收本技能时读取。`cases.json` 包含通用边界及多学科合成情境，不代表真实招生要求。

## 行为评测

1. 在隔离的临时目录中，用每条用例的 `prompt`、`evidence` 或 `source_rows` 作为输入。不给执行者 `expected` 和 `critical_failures`，也不给此前答案。
2. 有授权和运行条件时，分别运行无技能基线和加载本技能的版本；保持同一模型、输入和工具条件。用例指定不联网的就不联网，也不允许发消息或申请。不要仅为评测自行开通付费模型或外部账号。
3. 对照全部 `expected` 检查实际输出。任一 `critical_failures` 出现就失败；未满足任何一项预期也不能记为通过。
4. 记录模型、运行方式、输入、实际输出路径、通过项、失败项。基线没跑、独立评测没跑或其他模型没测都明确写“未执行”，不把自审当作独立实验。
5. 依据实际失败做最小修改，重跑失败用例及受影响用例。不要为了覆盖想象中的情况不断加规则。

元数据触发也需检查：文科转商科、设计选校、教育或健康职业路径、研究型申请、香港硕士定位、已有选校表删校应匹配；普通库存CSV清洗、仅代写PS不应匹配。不得只有计算机背景请求才能触发。真实多模型使用前分别测试目标模型。

## CSV 校验器测试

在 skill 根目录执行：

```bash
python3 -m unittest discover -s tests -v
```

工具使用标准库，无第三方依赖，只读源表和目标表。测试使用临时合成CSV，验证保标签、逗号转义、排除学校、重复项、BOM、列结构与错误退出。它不评估官网事实或分级质量。

## 验收分层

分别报告：技能格式、相对路径、脚本测试、行为评测、跨模型评测。前一层通过不代表后一层通过。保留审核草稿状态，未经用户批准不安装。
