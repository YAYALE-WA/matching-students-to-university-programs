# 官网证据、匹配与分级

## 每个项目的证据记录

使用一行一项目或等价结构，按任务需要保留以下信息。证据与判断放在不同字段，避免把建议写成官网事实。

| 信息组 | 最小内容 |
|---|---|
| 身份 | 学校实体、官方英文项目全名、官方中文名及来源、院系、校区／实际办学地点；涉及分校、合作办学时另核招生主体及学位授予方 |
| 学习内容 | 学位项目还是专修方向、核心课程、目标路线、论文／实践／创作组成、选课和分流限制 |
| 招生 | 目标入学季、自主申请／统考／推免等渠道、授课型／研究型、全日制／非全日制、学制、开放及截止日期、轮次、时区 |
| 资格 | 对应申请层次的学历、先修课及学分、学术标准、专项考试、行业经历、作品／写作样本、语言要求与有效期；仅核项目相关项 |
| 职业与研究路径 | 相关时核专业认证、执业转换、实习资格、导师接收机制和研究资源，不将入学与职业准入混为一谈 |
| 成本 | 学费币种、适用年度、按年／学分／整个项目收费、额外费用、是否待批准 |
| 证据 | 项目页及要求页 URL、关键依据摘要、页面适用年度、实际核查日期 |
| 判断 | 项目状态、个人资格状态、方向匹配理由、分级理由、预算结论、投递建议 |

## 三种状态独立核验

1. **项目存在**：官网有正式项目或课程目录。历史项目页不能证明仍招生。
2. **当季状态**：已开放／已公布但未开放／已截止／目标季未公布／待核实。官网有 Apply Now 按钮不能替代日期与入学季核验；本地和非本地轮次可能不同。
3. **个人资格**：已核条款符合／资格待核／目前不符合。“已核条款符合”针对当前申请阶段所需条件；官网明确允许应届申请或后补材料时可走该路径，同时保留补交前提。缺决定性信息则为“资格待核”。没有论文、编程或作品集只有在相关项目要求时才构成资格问题，不能跨学科套门槛。

用户说“确认可申请”时，不能只核验项目存在。对当前已开放且未发现硬性不符的项目，也要指出仍缺的个人材料。目标季尚未开放的可列规划名单，不标成当前可提交。

**可确认投递资格**需要：目标季已开放且未截止、当前申请阶段个人资格为“已核条款符合”，且满足客户硬性学校／校区／渠道范围。允许后补的毕业或材料前提随项目保留；这不是已获录取。预算独立判断：明确超硬上限则暂不建议投递；预算未定则经济可行性待定，不改写学术资格或录取分级，也不称成本可承受。其余记录保留为未来规划、条件候选或暂不投递，不计入已确认资格数量。“资格待核”不是学校给出的 conditional offer，不能混用。

作品集、写作样本等截止前必交材料尚未完成时，列条件候选，记录完成与提交节点；截止时仍缺则不符合提交要求。不要将可以准备的材料缺项直接写成永久无资格，也不把准备计划写成已完成。

每条关键事实绑定自己的来源，不用一个总链接支持所有字段：`事实字段｜条款摘要｜URL｜适用入学季｜核查日期｜正文/仅摘要｜冲突或缺项`。原文摘录限于核对所需短句；多个官网冲突未解决时保留双方依据，不覆盖为单一肯定结论。

## 取证方法

- 优先目标学年招生目录、对应学位层次的招生办公室要求、院系项目页及课程目录；职业准入问题同时查目标地区的官方监管／认证机构。官网口径冲突时核对学年、更新时间、批次和人群，不机械认定某个层级总是正确。
- 宽泛“相关专业”与具体先修条件可能是补充关系，应合并核对；“任何专业”与“仅限某专业”等同季互斥条款才构成直接冲突。适用关系无法确定时，最终个人状态统一为“资格待核（官网口径待确认）”，分别记各条款下的结果，不能同时给出两个互相矛盾的最终资格标签。
- 中介文章、论坛和同背景案例可发现线索，不能替代官网要求，也不能把个别案例变成录取概率。
- 搜索摘要用于定位。关键条款尽量打开正文确认；无法打开时注明只能核实到摘要，不补造正文内容。403、超时和搜索不到不等于停办。
- 保留相关条款中的 and／or、preferably、normally、equivalent 等限定，不把优先背景改写成绝对禁止，也不把工作经历替代路径漏掉。
- 明确“毕业后两年工作”与在校实习不同，按项目规定的截止或入学时间计算。未完成第二学士不能自动绕过第一学位条件。
- 新项目、改名、学位名称变更和校区变化需复核。课程、专修或研究方向不单独冒充独立学位项目。
- 母校、异地学校与合作项目逐项对齐实体、地点、招生渠道及学位授予方，不能互借门槛、学费或开放状态。历史方向仍在线、链接使用其他学院域名或网页标题错位，均须回到目标季目录核实；不能仅凭域名推断归属。用户限定七校不代表必须各填一个项目，无匹配也应记录筛查结论和来源。
- 官方未提供中文名称时，写“中文参考译名”，不能自称官方中文。若用户只接受官方双语名称，说明缺项。

## 判断顺序

先过资格和用户硬约束，再比较方向、基础及竞争力，最后组成投递组合。

**方向匹配**先核核心课程、研究训练或创作实践是否服务于学生目标；同名专业可能走完全不同的职业路线。说明目标所需内容是必修、选修还是校外可选活动。选修、分流、导师或实习可能有名额限制，不能承诺获得。

**路径比较**分别评估同专业、相邻专业和跨专业候选，只搜索用户接受的路线。对跨专业项目写清学校是否接收该背景、可迁移能力、缺失先修、可证实的补足路径和成本。补课意愿不等于已满足门槛；招生官未确认的替代资历不能自行认定等价。若偏好尚不明确，先提供少量方向对比再细化，不默认推荐计算机或商科。

**背景衔接**引用客户已提供的课程与成果：哪些支持先修要求，哪些弥补转专业距离，哪些仍待确认。论文、竞赛和实习的价值取决于真实贡献与相关性，不按标题机械加分。

为推荐理由建立具体链条：`学生目标 → 项目核心训练 → 已有背景证据 → 差距与条件 → 推荐／替代／不推荐`。方向适配、资格、竞争力和预算各自判断，不用一个总分掩盖硬约束。作品类、研究类和职业类项目分别看相应证据，禁止只按GPA统一排序。

**风险分级**是相对策略判断，不是量化录取预测。没有可靠且可比的数据时不输出百分比，不按院校名次或学校出身设固定阈值。

| 标签 | 使用依据 | 不应这样使用 |
|---|---|---|
| 冲刺 | 资格可走通或已明确注明资格前提，但学术竞争力、跨专业距离或成果证据存在明显短板 | 用“冲刺”掩盖已知硬性不符合 |
| 求稳 | 背景与先修匹配较清楚，材料支持较完整，作为本案相对主申更合理 | 达到最低均分或语言门槛就称稳录 |
| 保底 | 在允许的范围内，相比其他选择有更清楚的适配证据、较少资格障碍和可承受成本 | 为凑三档而把城大／理工等热门项目强行下调；承诺必录 |

不够支持某个标签时，分级写“待定位”；“条件候选”描述名单用途，不是第四个风险档位。若用户要求三档，可在有足够相对判断依据时暂定某档，并保留“资格待核”等限定；仍无法判断时说明无法可靠分档，不硬凑。允许保底为零；有条件备选不能伪装成已落实的风险兜底。

推荐申请数量随用户意愿、费用及可行项目调整，不默认投完所有参考项目。尽量避免组合全部依赖同一种尚未确认的资格。硬预算不符项目可留在扩展参考，但标记暂不投递。

核对同校／同院项目的多申限制、志愿顺序和最多发放 offer 数量。若共享选择机制，应明确组合依赖，不能把多个项目机械算成彼此独立的风险分散。

## 总预算

总成本 = 整个项目学费 + 全学制住宿生活费 + 必要附加支出 + 用户接受的预留。

- 先统一币种，记录汇率来源和日期；汇率和生活费估计使用区间，不制造精确承诺。
- 1.5 年、2 年项目计入对应月数，不能一律套一年生活费。学分收费核对最低学分及不收费学分。
- 分清已公布、拟议待批准、旧年度参考价格。未公布学费不能称预算已确认。
- 奖学金只有确定获得后才在基础预算中抵扣。兼职收入不作为满足硬预算的默认来源。
- 录取风险与经济可行性分开：超预算不意味着学术上更难，学术匹配高也不意味着适合推荐。
