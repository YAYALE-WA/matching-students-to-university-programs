# 跨地区、跨学科官方检索

先按客户的地区和学位层次定位招生渠道，再进入目标学科的院系和项目目录。本文中的香港入口只是可复用起点，不限制地区或学科。网址可能迁移，失效时从学校主站重新定位；每次按当前日期和目标入学季核验。

## 通用检索顺序

1. 学校官方招生目录或该地区官方申请平台：确认学位层次、申请人类别、办学地点与目标入学季。
2. 相关学院／系项目页和课程手册：核名称、课程结构、先修、作品集／写作样本／研究计划等专项条件。
3. 通用招生要求与项目要求交叉核对；奖学金、宿舍、实习、分流和导师名额单独查证，不因学校存在某项资源就认定本项目学生可获得。
4. 客户职业目标需要注册／执业时，再查就业目的地的官方监管或专业认证机构，不用其他地区规则替代。

可以组合 `site:官方域名 "目标专业或近义词" "admission"`、`"目标学年" "entry requirements"`、`"curriculum"`、`"portfolio"`、`"conversion"`、`"research proposal"` 等关键词。只用与该领域相关的词，不默认AI、编程或计算机。

## 检索扩展

其他地区从当地学校主站和官方申请渠道开始，不推测或拼造项目链接。用目标学科的正式名称、近义词与交叉方向检索，并以实际培养内容决定是否入选。先从官方导航或搜索找到页面，不将旧网址中的年份替换后当成已存在页面。

主站无法读取时可使用经官方链接确认的院系页、官方目录或官方 PDF 交叉核验。不要把商业学校子域名、镜像或搜索索引能打开直接解释成项目归属该学院。

不同地区、学位层次和申请人类别的机制分别核验，不沿用香港授课型硕士轮次、语言标准或分级。必要时明确资料缺口，不声称已穷尽所有合适项目。
