# 多学科路径匹配

只读与客户目标有关的领域。下表是需要调查的维度，不是所有学校共用的申请要求；是否必需、能否补修、能否用经历替代，必须回到具体项目官网。

## 从目标到候选

1. 将“想读商科／文科／理工”等宽泛意向细化到学习内容和毕业用途，例如职业转换、专业进阶、学术研究或创作实践。偏好未定时给少量路线对照，不替客户决定。
2. 建立目标学科的官方名称、常见近义名称和交叉方向关键词；不只搜与本科同名的专业，也不只搜校名排名。
3. 对用户接受的路径分别找候选：同专业进阶、相邻领域、跨专业转换。跨专业是否成立取决于实际课程、先修和招生路径，不按本科院系名称粗分。
4. 用课程或研究内容证明相关性。项目名出现目标关键词而核心培养不同，应降优先级或不推荐。背景很适配但偏离目标的项目只作经用户接受的替代项。

## 学科核查表

| 目标领域 | 需要比较的方向 | 重点核验与材料 | 避免误配 |
|---|---|---|---|
| 商科、管理、经济、金融、会计 | 学术经济／应用经济；定量金融／企业金融；一般管理／MBA；专业会计／转换路线 | 数学统计和经济学课程、项目指定考试、毕业后工作年限、行业经历、职业认证豁免 | 不将MBA与无工作经验的管理硕士混为一谈，不把所有商科都视为跨专业友好 |
| 法律、公共政策、公共管理 | 法律进阶／初始法律训练；政策研究／公共管理／国际事务 | 原法律学历是否必需、司法辖区、写作与方法训练、工作经验、课程与目标职业的关系 | 不将学术法律学位等同律师执业资格，不用政策项目替代用户想读的法律训练 |
| 教育、语言教学、特殊教育 | 教育研究／教师培养；语言教学／教育管理 | 教师资格、教学经验、目标教学语言、实习安排及资格、学科背景、观察或评估材料 | 教育学位不自动等同教师注册，也不默认所有教学项目都要求在职教师 |
| 心理、社会、社会工作、传播 | 实验／应用／临床心理；社会研究／社工专业训练；传播研究／媒体实践 | 心理学或方法学学分、统计训练、写作样本、相关服务经历、实习语言、专业认证 | 不将一般心理学当临床资格，不将传播都归为媒体制作，区分初始社工资格与进阶学位 |
| 人文、历史、文学、哲学、区域研究、翻译 | 研究型／应用型；文学研究／创意写作；翻译／语言学 | 学术写作、研究兴趣、阅读语言、文本分析、相关课程、翻译测试或作品 | 不普遍要求编程、实习或定量项目；语言成绩合格不代表已具备研究语言能力 |
| 艺术、设计、音乐、表演、电影、建筑 | 创作实践／理论研究；设计专项；建筑初始专业训练／后专业进阶 | 作品集或试演规范、创作过程和个人贡献、工作室训练、相关学位、面试与专业认证 | 不把作品集仅当加分项，不将不同建筑学位路线或短期设计课程混同 |
| 工程、计算机、数据、信息系统 | 工程专项／转换计算机／AI／数据分析／信息系统 | 具体数学、编程、工程与实验先修，项目成果，工程认证，非相关背景路径 | 不将所有理工项目都视为计算机，不将商科分析、统计理论和计算机训练混为一谈 |
| 数学、物理、化学、生命科学、环境、农业 | 理论／实验／应用／交叉研究 | 核心学科学分、实验技能、野外或实验室经历、研究方法、导师与设备需求 | 不把所有科学项目套用同一数学或编程门槛，避免遗漏实验和安全训练要求 |
| 医学、护理、药学、康复、公共卫生及其他健康领域 | 初始临床训练／已执业者进阶／非临床研究／公共卫生 | 专业学历、当前注册、临床年限、研究及统计基础、患者接触语言、实习地点与非本地资格 | 不将公共卫生或健康研究等同医生、护士或治疗师执业训练，不假设健康项目都只收医学本科 |
| 交叉学科或表中未列领域 | 按实际培养内容拆解，不按宣传名称归类 | 读取培养目标、必修结构、毕业产出、所属院系和实际先修，合并相关领域的核验项 | 不把表格当封闭分类；跨学科名称不意味着不需要前置基础 |

## 学位层次分支

- **本科**：从高中课程体系、学科选择、毕业资格、考试与地区申请渠道开始；转学另核学分和年级。不要索要不存在的本科GPA。
- **授课型硕士**：重点核相关学历、先修、课程路线、个人材料及毕业去向；区分专门接收转专业者与要求同专业进阶的项目。
- **研究型硕士／博士**：核研究主题、方法、导师或研究组匹配、项目接收机制、研究计划和资金。官网有导师名单不代表有名额；导师兴趣相符也不等于录取或资助。未授权不主动联系导师。
- **专业学位／桥梁／转换课程**：区分最终授予学位、预备阶段和转入条件；明确是否保证衔接、是否另行申请、是否增加学制成本，不把非学位课程冒充目标学位。

## 职业目标与申请目标分开

若学生目标涉及注册或执业，分别列学位入学资格、毕业后认证路径和就业地区要求。使用当前官方监管或认证来源核查，不凭学位名称或学校宣传保证职业资格。用户未提出相关职业目标时不额外增加大段执业说明。

若没有同时满足专业目标、地区、资格与预算的选择，明确指出冲突来自哪里，并比较有限的调整方案及代价。不要为了给出名单而擅自换专业、降学位层次或增加学校范围。
